# 模块二技术设计 v2.1：MoDE-Former+（覆盖率先验门控）

> 数据唯一来源：项目标准化特征/ 缺失测试集（aligned_50 对齐版本），未引入任何外部情感数据集。
> 本文档为最终方案（`final_v2`），在模块二 主模型之上完成改进，并补齐
> ①λ 网格搜索、②组件逐项消融、③连续 vs 分散缺失对照 三项实验。

## 一、改进动机（相对 v1 的差异）

v1 方案（`final`）有两个明确问题：

1. **门控对缺失不敏感**：v1 的 `α = softmax(g([h̄^T;h̄^A;h̄^V;c_T;c_A;c_V]))` 中覆盖率 `c_m`
   只是拼接进 MLP，实验显示不同缺失率下 `α` 几乎不变——模型无法按“有效区内还剩下多少信息”
   动态降低缺失模态的信任（这是可解释性/机制缺陷）。
2. **无效组件**：模态类型嵌入 `e^(m)` 与均值不变性损失 `L_inv` 在逐项消融中 ΔF1≈0（阴性结果）。

因此 v2.1 的改进是：

- **删除** `e^(m)`、`L_inv`；
- **新增覆盖率先验门控**：在 softmax 前显式加入 `β ⊙ log(c_eff)` 项，`β` 可学习；
- 保留 mask 感知 Transformer、跨模态注意力、MoE、KD、NLL 不确定性头；
- 训练策略微调：`MIN_EPOCHS=5`、KD 不退火、EMA=0、融合 dropout=0。

**诚实结论**（见第六节组件消融）：在 valid_a3 F1 上，MoE 是主要正贡献（+0.9pp）、KD 小幅正贡献（+0.1pp）、
覆盖率先验对 F1/MAE/Pearson 几乎中性（≈0）、NLL 对 F1 略负（−0.5pp）。
覆盖率先验的价值在于**机制正确性与可解释性**：它让门控 α 随缺失率单调变化（fv09），
而不是直接提升分类指标。v1→v2 的整体收益（test_a3 四指标提升）主要来自
**删除有害组件 + 训练策略修正 + MoE 保留**。

## 二、模型结构与数学表示

输入为三模态对齐序列 `X^(m) ∈ R^{50×d_m}`（`d_t=768, d_a=74, d_v=35`），
伴随 0/1 有效掩码 `M^(m) ∈ {0,1}^{50}`（`1`=有效，`0`=缺失/填充）。缺失位置特征置 0。

**L1 投影 + 位置编码**：
```
z^(m)_t = W_m x^(m)_t + PE_t ,  m∈{T,A,V}, t=1..50
```
其中 `W_m ∈ R^{128×d_m}`，`PE_t` 为正弦位置编码。缺失位特征已为 0，因此 `z` 在缺失位也只剩偏置+位置项。

**L2 mask 感知 Transformer**（`key_padding_mask = ¬M`）：
```
H^(m) = TransformerEncoder(z^(m); key_padding_mask=¬M^(m))
```
缺失位置被注意力屏蔽，且每层前向后再与 `M^(m)` 逐元素相乘，保证“0 不进信息流”。

**L3 跨模态注意力 + 模态内专家路由（MoE）**：
```
ê^(m) = LayerNorm( W_o h̄^(m) + Σ_{m'≠m} MHA_m(h̄^(m), H^(m'), H^(m')) )
h̃^(m) = Σ_{k=1}^{K} β^(m)_k E_k(ê^(m))
β^(m)  = softmax( r_m([ê̄^(m); c_m; ρ_m; s_m]) )
```
其中 `c_m` 为覆盖率，`ρ_m` 为有效区内缺失率，`s_m` 为缺失段数，`K=2`。
路由条件显式依赖缺失统计量，缺失越重越倾向“补全型”专家（思想来源 [7] EMOE/CVPR 2025）。

**L4 覆盖率先验门控（v2.1 新增核心）**：
```
c_eff^(m) = 1 − ρ_m
α = softmax( g([h̄^T;h̄^A;h̄^V;c^T;c^A;c^V]) + β ⊙ log(c_eff + ε) )
z = Σ_m α_m h̃^(m)
```
解释：`log(c_eff)` 是一个“先验信息量”项。当文本覆盖率趋近 0 时 `log(c_eff)→−∞`，
`α_text` 被强烈压低；当覆盖率=1 时该项=0，不干预。`β` 可学习（初值 0.5），
因此模型在“纯缺失驱动”与“内容驱动”之间自适应权衡。这是相对 v1 的关键机制修复：
**门控 α 随缺失率单调变化**（见 fv09）。

**L5 三头输出**：
```
P(y) = softmax(W_cls z + b_cls)             # 三分类极性
μ    = 3·tanh(w_reg^T z + b_reg)            # 情感强度 ∈ [−3,3]
logσ²= w_var^T z + b_var                    # 异方差不确定度
```

**L6 总损失（v2.1 最终）**：
```
L = L_cls + 0.3 L_reg + 0.1 L_rec + 0.5 L_kd(τ=3) + 0.1 L_nll
```
- `L_cls = −Σ w_y log P(y)`，`w` 为类别逆频权重 `w=[1.170,1.493,0.678]`（应对类别不平衡）；
- `L_reg = SmoothL1(μ, y)`（β=1，抗极端标签）；
- `L_rec`：跨模态重建，仅在挖洞位置监督；
- `L_kd = τ² KL(σ(z_S/τ) ‖ σ(z_T/τ))`：学生（残缺输入）模仿冻结教师（完整输入）软标签，τ=3（思想来源 [4] CMAD/ICCV 2025；[10] 计算机学报 2025）；
- `L_nll = ½[(y−μ)² e^{−logσ²} + logσ²]`（μ detach，只校准 σ；思想来源 [2] 不确定性感知/CVPR 2026）。

## 三、训练方案与选参

- 数据划分：train 3395 / valid 728 / test 727（aligned_50）。
- 标准化：仅按有效格（mask=1）统计 μ/σ；缺失/填充位置特征置 0 + mask=0。
- 缺失增强：`r~U(0.10,0.40)`、段长≤8、段数 1~4、每 batch 25% 完整样本。
- 优化：AdamW(lr=1e-4, wd=1e-2)，余弦退火（warmup 3 epoch），梯度裁剪 5.0，
  早停 patience=10，`MIN_EPOCHS=5`，3 种子 [42, 2024, 7]。
- 模型/超参选择分数：`score = F1_a3 + 0.2·Pearson_a3 − 0.3·MAE_a3`（验证集缺失测试集同分布缺失条件）。
- 决策阈值 τ（中性带宽）：验证集网格搜索 `τ∈[0,1]`，band 模式。

**关键参数表**

| 类别 | 参数 | 取值 |
|---|---|---|
| 输入 | 序列长度 L / 文本·语音·视觉维度 | 50 / 768·74·35 |
| 编码 | 隐维 HID / 头数 NHEAD / 层数 NLAYER / FFN | 128 / 4 / 2 / 256 |
| 编码 | Transformer dropout / 融合 dropout | 0.1 / 0.0 |
| MoE | 每模态专家数 K | 2 |
| 门控 | 覆盖率先验 β 初值 | 0.5 |
| 训练 | 种子 / batch / epochs / 早停 | [42,2024,7] / 64 / 40 / patience=10 |
| 优化 | AdamW lr / wd / 余弦 warmup / 梯度裁剪 | 1e-4 / 1e-2 / 3 epoch / 5.0 |
| 损失 | L = L_cls + λ_reg L_reg + μ_rec L_rec + λ_kd L_kd + λ_nll L_nll | λ_reg=0.3, μ_rec=0.1, λ_kd=0.5(τ=3), λ_nll=0.1 |
| 类别权 | w_y（负/中/正逆频） | [1.170, 1.493, 0.678] |
| 缺失增强 | r~U(0.10,0.40)；段长≤8；段数 1~4；完整样本比例 | 25%/batch |
| 缺失增强 | 缺模态个数分布 P_SUBSET{0,1,2,3} / 独立缺失概率 | {0.20,0.40,0.30,0.10} / 0.30 |
| 缺失测试集| 同分布注入 r / 段长≤4 / 三模态同位置 | 0.195 / 1~4 段 / 非独立 |
| 评价 | 决策阈值 τ / 模式 / 缺失评估抽样次数 | 0.05 / band / N=5(条件消融) |
| 选参 | 模型选择分数 | score = F1_a3 + 0.2·Pearson_a3 − 0.3·MAE_a3 |


**① λ 网格搜索（坐标下降）**：对 `λ_kd, λ_nll, λ_reg, λ_rec` 逐一坐标下降。
单种子（seed42）最优为 `kd=1.0, nll=0.05, rec=0.05`，但 3 种子复核后该配置过拟合，
最终取稳健默认 `kd=0.5, nll=0.1, reg=0.3, rec=0.1`。即“单种子坐标下降 + 3 种子复核，
最终用稳健默认”，体现验证集选参而非只在单种子挑最优。

**③ 连续 vs 分散对照**：同样缺失格数下，`连续单段` vs `多段分散(6段)`。
规律（10次随机注入 mean±std，见 fv18）：两者对缺失形态不敏感；连续单段 F1 随缺失率总体缓降（0.605→0.595），多段分散在低缺失率（≤10%）几乎无损、随缺失率增大同样缓降（0.605→0.592）。两者差距整体 ≤0.7pp 且误差棒基本重叠，说明鲁棒性来自 mask 感知编码与覆盖感知门控本身，而非依赖某种特定缺失几何形态。

### 错误归因结论（验证集 clean，3 种子软集成混淆矩阵，N=728，Acc=0.6195）

| 真实\预测 | Neg | Neu | Pos | 召回 |
|---|---|---|---|---|
| Neg | 131 | 44 | 31 | 0.636 |
| Neu | 33 | 101 | 50 | 0.549 |
| Pos | 39 | 80 | 219 | 0.648 |

（缺失测试集同分布缺失 a3 条件：Neg 132/43/31、Neu 32/101/51、Pos 39/83/216，与 clean 基本一致，见 fv07。）

- **主要错误模式仍是“中性塌缩”**：Pos→Neu 80（占 Pos 的 23.7%）、Neg→Neu 44（占 Neg 的 21.4%）是占比最高的两类误判；预测分布中 Neu 被多判 41 个（225 vs 真实 184）、Pos 被少判 38 个（300 vs 338），即模型把部分**弱正向样本坍缩到中性**。
- **Neutral 召回最低（0.549）**：中性类处于正负极端之间，判别边界最模糊，且 band 决策（|μ|<τ=0.05 强制判中性）会进一步把边界附近样本推入中性。
- **极端互混次之**：Neg→Pos 31（15.0%）、Pos→Neg 39（11.5%），主要出现在强情感但语义依赖上下文/反讽的样本。
- **与模块二设计目标的对应**：该“宁判中性、不极端误判”的保守倾向是缺失条件下鲁棒预测的合理代价——模型在证据不足时输出中性并配更高不确定度 σ，符合稳健性目标；代价是三分类 F1 被中性类拖低（macro-F1 0.607 与 Acc 0.619 的差距正源于此）。
- **不确定度校准（fv14）**：σ 与 |误差| 的 Pearson 相关 = 0.290，且按 σ 五分桶的 MAE 单调上升（0.395→0.510→0.551→0.774→0.793），说明异方差头输出的 σ 可作为强度不确定度的有效指示。


## 五、缺失条件消融规律（`final_v2` 软集成，验证集）

**缺失模态类型**（r=20%，10 次随机注入 mean±std）：
| 条件 | F1-macro | MAE | Pearson |
|---|---|---|---|
| 无缺失 | 0.6070 | 0.6047 | 0.6432 |
| 仅文本 | 0.6013±0.008 | 0.6085±0.002 | 0.6344±0.004 |
| 仅语音 | 0.6074±0.004 | 0.6039±0.001 | 0.6435±0.001 |
| 仅视觉 | 0.6065±0.004 | 0.6048±0.001 | 0.6439±0.001 |
| 文本+语音 | 0.6019±0.006 | 0.6076±0.003 | 0.6348±0.005 |
| 文本+视觉 | 0.6016±0.007 | 0.6088±0.003 | 0.6350±0.005 |
| 语音+视觉 | 0.6082±0.005 | 0.6041±0.001 | 0.6441±0.001 |
| 三模态 | 0.6023±0.007 | 0.6077±0.003 | 0.6355±0.005 |

结论：**凡涉及文本缺失的条件 F1 均低于不含文本缺失的条件**（0.6013~0.6023 vs 0.6065~0.6082），
文本局部缺失对 F1 影响最大（仅文本 −0.6pp）；语音/视觉局部缺失几乎无损失甚至略升
（在噪声范围内），说明模型主要依赖文本，语音/视觉为辅助证据。

**缺失位置**（r=30% 单段，确定性干预）：文本前段 F1 0.5777 < 后段 0.5858 < 中段 0.5990；
语音/视觉对位置不敏感。结论：文本的**前段（语义开头）最敏感**。

**缺失率**（10 次随机注入 mean±std）：F1 从 0.6070 缓降至 0.6006~0.6029 区间，
整体降幅约 0.4~0.6pp（最低出现在 r=30%），各档误差棒基本重叠，未见单调崩塌；
MAE 缓升 0.6047→0.6085~0.6097，Pearson 缓降 0.6432→0.6345，
证明 `0+mask` 闭环 + 覆盖率先验门控在 r=0~50% 范围内保持鲁棒。

**缺失时长**（单段连续）：三模态 L=16 时 F1 0.5398、L=40 时 0.4937；
仅文本 L=16 时 0.5534；仅语音/视觉对时长基本不敏感。
结论：**连续缺失越长越难恢复**，且主要脆弱点仍在文本模态。

**极端缺失**：仅文本全缺失 F1 0.5090 / MAE 0.7081 / Pearson 0.4505（最大崩塌）；
仅语音/仅视觉全缺失基本无损（0.5996 / 0.5944）；三模态 70% 仍 F1 0.5800。

## 六、组件逐项消融（v2.1，3 种子，valid_a3，逐模型 mean±std）

| 变体 | F1-macro | Acc | MAE | Pearson | ΔF1 |
|---|---|---|---|---|---|
| final_v2（全开） | 0.5993±0.0022 | 0.6094 | 0.6366 | 0.6141 | 0 |
| −覆盖率先验 | 0.5993±0.0013 | 0.6094 | 0.6367 | 0.6139 | ≈0.00 |
| −知识蒸馏 | 0.5986±0.0056 | 0.6140 | 0.6371 | 0.6083 | −0.07 |
| −专家路由 | 0.5903±0.0132 | 0.6016 | 0.6510 | 0.6013 | **−0.90** |
| −不确定性头 | 0.6042±0.0009 | 0.6158 | 0.6381 | 0.6117 | +0.49 |

结论（诚实归因）：
1. **MoE 是主要正贡献**：去掉后 F1 −0.9pp、MAE +1.4pp（0.6366→0.6510），是鲁棒性的核心来源；
2. **KD 小幅正贡献**：−0.07pp，次要；
3. **覆盖率先验对 F1/MAE/Pearson 中性**：其价值在机制与可解释性（fv09 门控随缺失率单调），不在分类指标；
4. **NLL 对 F1 略负（−0.5pp）**：保留它是因为输出不确定度 σ（第四节错误归因中的不确定度校准 fv14），是“另一条腿”的贡献而非分类增益。

净结论：v2.1 相对 v1 的收益主要来自 **MoE 保留 + 删除有害组件（e^(m)、L_inv）+ 训练策略修正**。
