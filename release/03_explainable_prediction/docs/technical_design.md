# 模块三：原生证据加权融合（AEF）的建模与结果

> 本文档与 `reproduction.md` 配套：前者讲“为什么这样设计”，后者讲“怎么跑、跑到什么程度”。
> AEF 为主模型，后验解释基线作为对照进入显著性检验。

## 1. 建模思路

模块三面向“三模态信息完整、但决策依据难以追溯”的场景。核心难点有二：

1. **重要性必须可量化、可比较**：注意力权重等内部量既非归一化、又不具备因果语义，难以横向比较三模态的作用差异。
2. **解释必须与预测同源**：若在推理期用“黑盒扰动”事后补一个解释，解释与决策不共享同一条前向链路，难以保证忠实。

据此，AEF不采用“先预测、后解释”的后验方案，而是在模块二的鲁棒融合骨干上引入**原生证据加权融合（AEF）**：
证据权重在前向计算中直接决定三模态如何汇聚，解释与预测出自同一条计算图，从机理上保证“解释了的就是被用于预测的”。
后验的 Shapley 值与留一扰动仅作为模型无关的互证，不作为主口径。

## 2. 输入接口（沿用模块二）

三模态对齐特征与有效掩码：

- X^(m) ∈ R^{50×d_m}，m ∈ {T, A, V}，d_T=768、d_A=74、d_V=35；
- M^(m) ∈ {0,1}^{50} 为有效掩码（补位 0 的位置 mask=0）。

每个模态先经冻结的模块二单模态 Transformer 编码器得到隐藏表示 h^(m)(t) ∈ R^{128}。

## 3. 原生证据加权池化（核心创新）

每个模态配备一个证据打分器 Ev^(m)：R^{128}→R（单个线性层）：

- 证据打分：s^(m)(t) = Ev^(m)(h^(m)(t))。
- 原生证据（供可视化与阈值定位）：e^(m)(t) = σ(s^(m)(t)) ∈ (0,1)。
- 证据加权池化（替代均值池化，核心改动）：
  ē^(m)(t) = softmax_t( s^(m)(t) | mask_m(t)=1 )，
  p^(m) = Σ_t ē^(m)(t) · h^(m)(t)。

关键点：ē^(m)(t) 直接参与前向池化并接受梯度回传，因此“哪个位置的哪个模态重要”在训练中自然养成，
而不是推理期事后补一个解释。

## 4. 跨模态融合与覆盖率先验门控

- 对每个模态池化结果 p^(m) 做跨模态注意力与模态内专家路由（MoE，K=2），得到 enriched^(m)。
- 覆盖率先验门控：
  α = softmax( Gate([p^T, p^A, p^V, coverage]) + β · log coverage )，
  完整数据下 coverage=1，先验退化为常数；α_m 即“该模态在融合中占多少”（模态作用程度）。
- 融合：z = Σ_m α_m · enriched^(m)(p^(m))。

## 5. 三头输出

融合表示 z 分别进入三个输出头：

- 极性分类头：p(y) = softmax(W_c z + b_c)，三分类 Negative/Neutral/Positive；
- 强度回归头：ŝ = 3·tanh(w_r^T z)，输出连续情感强度；
- 不确定度头：σ² = exp(w_v^T z)，异方差高斯，σ 作为强度预测不确定度。

## 6. 目标函数与训练

多任务目标：

L = L_cls + λ1 L_reg + λ2 L_nll

- L_cls：类别逆频加权交叉熵，权重 [1.170, 1.493, 0.678]；
- L_reg = SmoothL1(μ, y)；
- L_nll = 0.5[(y−μ̄)² exp(−log σ²) + log σ²]，μ̄ 为停止梯度后的强度预测；
- λ1=0.3、λ2=0.1。

训练采用“冻结编码器、微调融合与解释头”的热启动：以模块二三个种子最终权重初始化（strict=False），
冻结单模态投影与编码器（907,520 参数），仅更新证据头、跨模态注意力、专家路由、门控与输出头（613,542 参数）。
AdamW（lr=1e-4、wd=0.01）、线性预热 + 余弦衰减、梯度裁剪 5.0、最多 20 轮早停；种子 {42, 2024, 7}
三种子软平均集成；决策阈值 τ 逐种子以宏 F1 最优选取（集成后 τ=0.0833）。

## 7. 可解释性输出

1. **模态作用程度 α**：门控输出，直接可读、可跨样本比较（主口径）。
2. **主要参考模态**：取 argmax_m α_m（或 Shapley 主导口径互证）。
3. **关键证据定位**：对主要参考模态取 ē^(m)(t) 的 top-k 槽位。
4. **Shapley 互证（模型无关）**：φ_m = Σ_{S⊆M\{m}} w(|S|)[v(S∪{m})−v(S)]，与 α 做主导一致率与 Spearman 相关。
5. **证据回看**：利用模块一建立的词级时间戳，把证据槽位 t 映射到原始时间区间 [t·T/50, (t+1)·T/50)，
   得到支撑判断的原始词、语音时段与视觉关键帧。

## 8. 对照基线：后验基线（后验解释）

后验基线完整复用模块二骨干做预测，解释在推理期后验叠加：

- 模态归因：Shapley 值 φ_m；
- 局部证据：遮挡 LOPO（逐位置置 0 看预测信心下降 I_m(t)）；
- 解释不参与训练，故语音/视觉位置级证据不优于随机（见第 9 节）。

## 9. 两方案对比与选择

| 指标 | 后验基线（后验基线） | AEF（原生证据加权融合） |
| --- | --- | --- |
| Accuracy | 0.6195 | 0.6113 |
| Macro-F1 | 0.6070 | 0.5961 |
| MAE | 0.6047 | 0.6258 |
| Pearson r | 0.6432 | 0.6301 |
| 文本证据胜率 | 0.695 | 0.580 |
| 语音证据胜率 | 0.405（不优于随机） | 0.625（优于随机） |
| 视觉证据胜率 | 0.364（不优于随机） | 0.581（优于随机） |
| 可解释测试集主导模态 | 文本 20/20 | 文本 16 / 语音 4 / 视觉 0 |
| α–Shapley 主导一致率 | 0.955 | 0.745 |

**选择结论**：采用 AEF 作为主模型。理由：模块三的核心设计重点是“可解释性、可量化、可复核”，
而非单纯刷分类指标。后验基线的语音/视觉局部证据经不起忠实度检验，是审阅者核对时一定会看到的方法缺陷；
AEF 以约 1 个百分点的分类代价换来“三模态局部证据都忠实 + 主导模态更多样 + 解释与决策同源”，
更贴合模块三目标。这一“精度—可解释性”权衡在文档中如实说明，不做过拟合式美化。

## 10. 结果速查

- 验证集（N=728，三种子软集成）：Acc 0.6113 / F1 0.5961 / MAE 0.6258 / Pearson 0.6301 / τ=0.0833。
- 逐类：Negative 206（acc 0.626 / F1 0.640 / MAE 0.804）；Neutral 184（0.505 / 0.465 / 0.498）；
  Positive 338（0.660 / 0.683 / 0.587）。
- 混淆矩阵：[[129,44,33],[32,93,59],[36,79,223]]。
- 可解释测试集（20 条）：极性分布 7/6/7；主导模态 文本 16 / 语音 4 / 视觉 0；平均门控 α=[0.608, 0.206, 0.186]。
- 错误归因三点：中性塌缩（Neutral 召回最低 0.505，正类误判中性 79 条）；视觉证据偏弱（视觉主导 0 条）；
  证据过度集中加剧误判（判错样本证据熵更低）。
