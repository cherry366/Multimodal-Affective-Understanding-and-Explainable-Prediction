# Weight Storage & Precision

为降低仓库体积，模型权重以 **fp16（半精度）** 保存；推理加载时统一转回 **fp32**，不改变网络结构与评估口径。

## 权重清单

| 模块 | 文件 | 原始 fp32 | 仓库内 fp16 |
| --- | --- | --- | --- |
| 鲁棒预测 | `final_v2_s42.pt / s7.pt / s2024.pt` | 6.49 MB ×3 | 3.27 MB ×3 |
| 可解释预测 | `q3v2_s42.pt / q3v2_s7.pt / q3v2_s2024.pt` | 5.87 MB ×3 | 2.96 MB ×3 |

## 加载方式

- `train_q2.py` 的 `load_ckpt()` 在加载时把 state 中的半精度张量统一转换为 `float32`；
- 可解释预测模块复用同一加载入口，因此无需额外转换；
- 三种子采用软集成：分类概率、强度预测与不确定度分别取平均。

## 精度核验

| 模块 | 指标 | fp32 | fp16 加载 | 差值 |
| --- | --- | --- | --- | --- |
| 鲁棒预测 | Accuracy | 0.619505 | 0.619505 | 0 |
| 鲁棒预测 | Macro-F1 | 0.606998 | 0.606998 | 0 |
| 鲁棒预测 | MAE | 0.604718 | 0.604721 | +3e-6 |
| 鲁棒预测 | Pearson | 0.643224 | 0.643225 | ≈0 |
| 可解释预测 | Accuracy | 0.611264 | 0.611264 | 0 |
| 可解释预测 | Macro-F1 | 0.596067 | 0.596067 | 0 |
| 可解释预测 | MAE | 0.625790 | 0.625753 | −4e-5 |
| 可解释预测 | Pearson | 0.630140 | 0.630142 | +2e-6 |

结论：分类指标在四位小数内完全一致；回归指标仅在小数点后第 5～6 位变化，不影响报告精度。

## 说明

- 若需要复现 fp32 原始数值，请从训练流程重新训练（`train_q2.py` / `train_q3v2.py`）。
- 特征文件 `.pkl.gz` 为无损压缩，可用 `features/restore_pkl.py` 逐字节还原，与权重精度压缩不同。
